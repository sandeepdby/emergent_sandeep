# RCA — InsureHub / endorsement-ai PRODUCTION: "no data + uploads don't appear" across all modules

## TL;DR
Production is **not** a bad deploy, empty DB, missing secret, or crashed pod. The latest image is live, healthy, and pointed at the correct populated database. The outage is a **runtime 500 on JSON serialization**: at least one production record contains a non-finite float (`NaN` or `Infinity`), and FastAPI's default `JSONResponse` serializes with `json.dumps(..., allow_nan=False)`, which raises `ValueError: Out of range float values are not JSON compliant`. Every list/aggregate endpoint that includes such a record returns HTTP 500, so the whole UI appears empty/broken. Preview works only because its DB has clean data.

**Fix owner: E1 (source code).** Add non-finite-float sanitization before returning Mongo data, and clean the offending stored values.

## Why preview passed but prod failed
Same code, different data. Preview's local Mongo has clean numeric values; production accumulated at least one non-finite float (bad import row and/or a divide-by-zero at write time). The code never guards against non-finite floats at serialization, so it only manifests on the data that contains them.

## Fix (source — E1 to apply, then redeploy)
Two parts — do BOTH:

### 1) Stop the crash (code) — sanitize non-finite floats before serialization
Robust global option — recursively replace `NaN`/`±Inf` with `None` for anything returned from Mongo. Add a helper and apply it to endpoint return values (or centralize via a custom response class):
```python
import math

def clean_floats(obj):
    if isinstance(obj, float):
        return obj if math.isfinite(obj) else None
    if isinstance(obj, dict):
        return {k: clean_floats(v) for k, v in obj.items()}
    if isinstance(obj, list):
        return [clean_floats(v) for v in obj]
    return obj
```
Apply at each Mongo-reading endpoint, e.g. `return clean_floats(docs)`, or wrap globally.

Cleaner global alternative — switch the default response class to ORJSON (orjson serializes non-finite floats as `null` by default), if `orjson` is acceptable to add:
```python
from fastapi.responses import ORJSONResponse
app = FastAPI(default_response_class=ORJSONResponse)
```
(Prefer the explicit `clean_floats` sanitizer if you want `None` semantics guaranteed and to avoid a new dependency.)

### 2) Prevent re-introduction (write path) + clean existing data
- At the point where prorata / per-life / ratio values are computed, guard the divisor: if `days_in_policy_year == 0` (or any denominator is 0), set the result to `0`/`None` instead of dividing → prevents new `NaN`/`Inf` from being stored.
- Data cleanup: scan `endorsements`, `policies`, and `cd_ledger` for non-finite numeric fields (e.g. `prorata_premium`, `per_life_premium`, `annual_premium_per_life`, and any stored ratios) and repair them (recompute with the guarded formula, or set to `0`/`null`). This restores the affected records immediately even before the guard prevents future ones.
